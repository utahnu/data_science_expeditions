# Cube Sums by Leading Digit

## Description
Write a function that takes the first `n` cubes (`[1^3, 2^3, ..., n^3]`), keeps the cubes whose leading digit is even, adds them, and prints the result.

## Permitted Libraries

```
import numpy
import math
import argparse
import os
```

## Deliverables
1. A single .py file with your code with a single function. Be sure to print the output exactly as the test cases show.

2. Your program takes a single input argument `--n`




## Test Cases


### Test Case 1:

Input:

`python cube_sums.py --n 4`

Output:

`cube(4) = 99`

### Test Case 2:

Input:

`python cube_sums.py --n 5`

Output:

`cube(5) = 99`

### Test Case 3:

Input:

`python cube_sums.py --n 25`

Output:

`cube(25) = 29124`
